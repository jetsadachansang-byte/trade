# trade

บอทเทรด (Expert Advisor) สำหรับ MetaTrader 5 พร้อมระบบตั้ง TP/SL อย่างเหมาะสม

## ไฟล์หลัก

- `MQL5/Experts/TradeTemplate_TP_SL.mq5` — EA template ภาษา MQL5

## ฟีเจอร์

- **ตั้ง SL/TP ได้ 2 โหมด**
  - `Fixed points` — กำหนดระยะ SL/TP เป็นจุด (points) ตายตัว
  - `ATR-based` — คำนวณ SL จากค่า ATR × ตัวคูณ (ปรับตามความผันผวนของตลาดอัตโนมัติ) และ TP จากอัตราส่วน Reward:Risk (ค่าเริ่มต้น 2:1)
- **คำนวณขนาด Lot ตามความเสี่ยง** — กำหนดความเสี่ยงต่อไม้เป็น % ของ balance (ค่าเริ่มต้น 1%) ระบบจะคำนวณ lot ให้พอดีกับระยะ SL หรือจะใช้ lot คงที่ก็ได้
- **ตรวจสอบข้อจำกัดของโบรกเกอร์** — เช็ค stops level และ spread ก่อนส่งคำสั่ง เพื่อไม่ให้ SL/TP ใกล้ราคาเกินไปจนถูกปฏิเสธ พร้อมปรับ lot ให้ตรงกับ min/max/step ของโบรกเกอร์
- **Breakeven** — เลื่อน SL มาที่จุดเข้า (บวก offset เล็กน้อย) เมื่อกำไรถึงจุดที่กำหนด เพื่อล็อกไม่ให้ขาดทุน
- **Trailing Stop** — เลื่อน SL ตามราคาเมื่อกำไรวิ่ง เพื่อล็อกกำไรเพิ่มขึ้นเรื่อย ๆ
- **สัญญาณตัวอย่าง: MA Crossover** — EMA 20 ตัด EMA 50 (แก้ฟังก์ชัน `GetSignal()` เพื่อใส่กลยุทธ์ของคุณเองได้)
- เข้าเทรดครั้งเดียวต่อแท่งเทียน และจำกัดจำนวน position พร้อมกัน (มี magic number แยกจาก EA อื่น)

## วิธีติดตั้ง

1. เปิด MetaTrader 5 → กด `Ctrl+Shift+D` หรือเมนู **File → Open Data Folder**
2. คัดลอกไฟล์ `TradeTemplate_TP_SL.mq5` ไปไว้ที่โฟลเดอร์ `MQL5/Experts/`
3. เปิด MetaEditor (กด `F4` ใน MT5) → เปิดไฟล์ → กด **Compile** (`F7`)
4. กลับมาที่ MT5 ลาก EA จากหน้าต่าง Navigator ไปวางบนกราฟ
5. เปิดใช้งาน **Algo Trading** (ปุ่มบนแถบเครื่องมือ)

> ⚠️ **ควรทดสอบใน Strategy Tester และบัญชี Demo ก่อนใช้เงินจริงเสมอ**

## พารามิเตอร์สำคัญ

| พารามิเตอร์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `InpRiskPercent` | 1.0 | ความเสี่ยงต่อไม้ (% ของ balance) |
| `InpFixedLot` | 0.0 | lot คงที่ (0 = ใช้ % ความเสี่ยง) |
| `InpSLTPMode` | ATR | โหมดคำนวณ SL/TP |
| `InpATRMultSL` | 1.5 | ตัวคูณ ATR สำหรับระยะ SL |
| `InpRewardRatio` | 2.0 | อัตราส่วน TP ต่อ SL (Reward:Risk) |
| `InpSLPoints` / `InpTPPoints` | 300 / 600 | ระยะ SL/TP แบบ fixed (points) |
| `InpUseBreakeven` | true | เปิดใช้ breakeven |
| `InpBEProfitPoints` | 300 | กำไรกี่จุดจึงเลื่อน SL มาจุดเข้า |
| `InpUseTrailing` | true | เปิดใช้ trailing stop |
| `InpTrailStart` / `InpTrailDistance` | 400 / 250 | เริ่ม trailing เมื่อกำไรถึง / ระยะห่างจากราคา |
| `InpFastMAPeriod` / `InpSlowMAPeriod` | 20 / 50 | คาบ MA เร็ว/ช้า ของสัญญาณตัวอย่าง |

## หลักการตั้ง TP/SL ที่ใช้ใน EA นี้

1. **SL ต้องมีเหตุผลทางเทคนิค** — โหมด ATR ทำให้ SL กว้างขึ้นเมื่อตลาดผันผวนและแคบลงเมื่อตลาดนิ่ง ลดโอกาสโดน SL จาก noise
2. **TP อิงอัตราส่วน Reward:Risk** — ค่าเริ่มต้น 2:1 หมายถึงชนะ 1 ไม้ชดเชยแพ้ได้ 2 ไม้ ทำให้ระบบมีกำไรได้แม้ winrate ต่ำกว่า 50%
3. **ขนาด lot ต้องมาจากระยะ SL** — ไม่ใช่ตั้ง lot ก่อนแล้วค่อยหา SL เพราะจะทำให้ความเสี่ยงต่อไม้ไม่คงที่
4. **ล็อกกำไรเมื่อราคาวิ่งไปทางเรา** — breakeven ตัดความเสี่ยงเป็นศูนย์ก่อน แล้ว trailing stop ค่อยเก็บกำไรส่วนที่เหลือ
