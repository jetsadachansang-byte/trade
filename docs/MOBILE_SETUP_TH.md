# ตั้งค่าสัญญาณเข้า Telegram จากมือถือ (ไม่ต้องใช้คอม ไม่ต้องเปิด MT5)

ระบบนี้ให้ **GitHub รันการวิเคราะห์ให้ฟรี** ตามเวลาที่ตั้งไว้ แล้วส่งสัญญาณเข้า Telegram
ทุกขั้นตอนทำบนมือถือได้ ใช้เวลาประมาณ 15 นาที ตั้งครั้งเดียวจบ

```
[ GitHub รันให้ฟรีทุก 30 นาที ]         [ มือถือคุณ ]
   ดึงราคา → วิเคราะห์ SMC     ──────►   Telegram เด้งสัญญาณ
   ติดตาม TP/SL ให้ต่อเนื่อง               เปิดออเดอร์ในแอปโบรกเกอร์
```

**ไม่ต้องเปิดคอม ไม่ต้องมี VPS ไม่ต้องติดตั้ง MT5**

## ขั้นที่ 1 — สร้างบอทใน Telegram (ทีละหน้าจอ)

### 1.1 เปิดแอป Telegram แล้วค้นหา BotFather

1. เปิดแอป **Telegram** บนมือถือ
2. แตะ **ไอคอนแว่นขยาย 🔍** มุมขวาบน
3. พิมพ์: `@BotFather`
4. จะมีรายการขึ้นมาหลายตัว — **เลือกตัวที่ชื่อ "BotFather" และมีเครื่องหมายติ๊กสีฟ้า ✅ ข้างชื่อ**

> ⚠️ มีบอทปลอมชื่อคล้ายกันเยอะมาก **ต้องมีติ๊กสีฟ้าเท่านั้น** ตัวจริงมีผู้ติดตามหลักล้าน

### 1.2 กด Start

แตะปุ่ม **START** สีฟ้าด้านล่างจอ

BotFather จะตอบกลับมาเป็นข้อความยาว ๆ ประมาณนี้:
```
I can help you create and manage Telegram bots.
You can control me by sending these commands:

/newbot - create a new bot
/mybots - edit your bots
...
```

### 1.3 สั่งสร้างบอทใหม่

พิมพ์ในช่องแชท: `/newbot` แล้วกดส่ง

BotFather ตอบ:
```
Alright, a new bot. How are we going to call it?
Please choose a name for your bot.
```

### 1.4 ตั้งชื่อบอท (ชื่อที่จะแสดง)

พิมพ์ชื่ออะไรก็ได้ ภาษาไทยหรืออังกฤษก็ได้ เช่น:
```
CapitalGuard Signal
```

BotFather ตอบ:
```
Good. Now let's choose a username for your bot.
It must end in `bot`. Like this, for example:
TetrisBot or tetris_bot.
```

### 1.5 ตั้ง username (ต้องไม่ซ้ำใครทั้งโลก)

**กติกา:** ภาษาอังกฤษ ตัวเลข ขีดล่างเท่านั้น และ**ต้องลงท้ายด้วย `bot`**

พิมพ์ เช่น (ใส่เลขหรือชื่อตัวเองต่อท้ายให้ไม่ซ้ำ):
```
jetsada_signal_2026_bot
```

**ถ้าซ้ำ** BotFather จะตอบ `Sorry, this username is already taken.` → พิมพ์ชื่อใหม่ไปเรื่อย ๆ จนผ่าน

### 1.6 รับ Token ← ขั้นสำคัญที่สุด

เมื่อผ่าน BotFather จะตอบแบบนี้:
```
Done! Congratulations on your new bot.
You will find it at t.me/jetsada_signal_2026_bot

Use this token to access the HTTP API:
8123456789:AAHk3_xYzAbCdEfGhIjKlMnOpQrStUvWxYz

Keep your token secure and store it safely.
```

**บรรทัดที่เป็นตัวเลขยาว ๆ มีเครื่องหมาย `:` ตรงกลาง คือ token ของคุณ**

👉 **แตะค้างที่ข้อความ token → เลือก Copy** เก็บไว้ก่อน (จะใช้ในขั้นที่ 3)

> 💡 เก็บ token ไว้ที่ไหนดี: ส่งข้อความหาตัวเองใน Telegram (แชท "Saved Messages") จะหาเจอง่าย
> 🔒 **ห้ามส่งให้ใครเด็ดขาด** ถ้าหลุด พิมพ์ `/revoke` กับ BotFather เพื่อยกเลิกและออกใหม่

## ขั้นที่ 2 — เพิ่มบอทเข้าแชทและหา Chat ID

### 2.1 เปิดแชทกับบอทที่สร้าง

**วิธีที่ง่ายที่สุด:** ในข้อความที่ BotFather ตอบมา จะมีลิงก์ `t.me/ชื่อบอทของคุณ` → **แตะลิงก์นั้น** จะเด้งเข้าแชทบอททันที

หรือค้นหาเอง: แตะ 🔍 → พิมพ์ username ที่ตั้งไว้ (เช่น `jetsada_signal_2026_bot`)

### 2.2 กด START ← ข้ามไม่ได้เด็ดขาด

แตะปุ่ม **START** สีฟ้าด้านล่าง

จอจะยังเงียบ ๆ ไม่มีอะไรตอบกลับ — **ถูกต้องแล้ว** เพราะบอทเรายังไม่มีโค้ดตอบข้อความ
แต่การกด START คือการ**อนุญาตให้บอทส่งข้อความหาคุณได้** ซึ่งเป็นกฎของ Telegram

> ⚠️ **ถ้าไม่กด START ระบบจะส่งสัญญาณหาคุณไม่ได้เลย** และจะขึ้น error 400 ใน log

### 2.3 หา Chat ID ของคุณ

Chat ID คือเลขประจำตัวบัญชี Telegram ของคุณ ใช้บอกระบบว่าจะส่งสัญญาณไปหาใคร

1. แตะ 🔍 → พิมพ์: `@userinfobot`
2. เลือกบอทชื่อ **userinfobot**
3. แตะ **START**
4. บอทจะตอบกลับมาทันที:
```
Id: 123456789
First: Jetsada
Lang: th
```

👉 **เลขหลัง `Id:` คือ Chat ID ของคุณ** — แตะค้างเพื่อคัดลอกเก็บไว้

## รายงานวิเคราะห์กราฟ (ส่งเป็นระยะ)

นอกจากสัญญาณเข้าเทรด ระบบยังส่ง**รายงานภาพรวมตลาด**ให้ทุก 1 ชั่วโมง (ปรับได้) เพื่อให้เห็นว่ากราฟกำลังทำอะไรอยู่ แม้ยังไม่มีจุดเข้า

```
📈 วิเคราะห์กราฟ — ภาพรวมตลาด
สัญญาณวันนี้ 0 · กำลังติดตาม 0
━━━━━━━━━━━━━━
📊 XAUUSD  @ 3117.67
แนวโน้ม: D1 ขาขึ้น ▲ | H4 ขาขึ้น ▲
　　　　 H1 ขาขึ้น ▲ | เข้า ขาขึ้น ▲
ทิศทางที่ระบบมอง: BUY
🔺 แนวต้าน/BSL: 3150.13
🔻 แนวรับ/SSL: 3096.46  (Equal Lows)
🟢 โซน: Discount (rangePos 0.32)
🧠 BOS ✔ · Sweep ล่าง ✔ · FVG ✔ (mitigated)
🎯 Order Block: 3097.96 – 3100.94
　 คุณภาพ 73/100 · ราคาอยู่ในโซนแล้ว
📏 ATR: 5.14
ความคืบหน้า: █████████░░ 9/11
🔥 คะแนน 84 < 90
```

**อ่านยังไง:**

| บรรทัด | ความหมาย |
|---|---|
| แนวโน้ม 4 TF | โครงสร้างแต่ละ timeframe (ต้องตรงกันถึงจะเข้าได้) |
| ทิศทางที่ระบบมอง | ผลสรุปจาก D1/H4/H1 — ถ้าขึ้น "ยังไม่ชัด" แปลว่า TF ขัดกัน |
| 🔺 แนวต้าน/BSL | Swing High ล่าสุด = จุดที่ stop ของคนขายกองอยู่ (เป้าราคา) |
| 🔻 แนวรับ/SSL | Swing Low ล่าสุด = จุดที่ stop ของคนซื้อกองอยู่ |
| Equal Highs/Lows | มี liquidity pool สะสม → ราคามักวิ่งไปกวาด |
| 🟢/🔴 โซน | Discount = ราคาถูก (เหมาะซื้อ) · Premium = ราคาแพง (เหมาะขาย) |
| 🎯 Order Block | โซนที่สถาบันเข้าไม้ พร้อมคะแนนคุณภาพ และบอกว่าราคาเข้าโซนหรือยัง |
| ความคืบหน้า | ผ่าน SMC pipeline กี่ขั้นจาก 11 — **ยิ่งใกล้ 11 ยิ่งใกล้ได้สัญญาณ** |
| 🔥 vs ⏳ | 🔥 = ผ่านแล้ว 8 ขั้นขึ้นไป (ใกล้มาก) · ⏳ = ยังอีกไกล |

สินทรัพย์ที่**ใกล้ได้สัญญาณที่สุดจะอยู่บนสุด**เสมอ

**ปรับความถี่:** ตั้ง Variable `BRIEFING_MINUTES`
- `60` = ทุกชั่วโมง (ค่าเริ่มต้น)
- `30` = ทุกครึ่งชั่วโมง
- `15` = ทุก 15 นาที
- `5` = ทุกรอบสแกน (**~288 ข้อความ/วัน — เยอะมาก**)
- `0` = ปิดรายงาน เอาเฉพาะสัญญาณ

> ⚠️ รายงานนี้**ไม่ใช่สัญญาณเข้าเทรด** เป็นแค่ภาพรวมให้ติดตามตลาด
> จุดเข้าจริงจะส่งมาแยกอีกข้อความพร้อม Entry Zone / SL / TP1-3 ครบ

## ปรับแต่งค่าต่าง ๆ (ทำทีหลังได้)

**Settings → Secrets and variables → Actions → แท็บ Variables → New repository variable**

| ชื่อ Variable | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `TIER1_SYMBOLS` | `XAUUSD` | สินทรัพย์หลัก |
| `TIER2_SYMBOLS` | `EURUSD,GBPUSD,USDJPY` | คู่เงินหลัก |
| `TIER3_SYMBOLS` | (ว่าง) | คู่เงินรอง เช่น `EURJPY,GBPJPY` |
| `SCORE_THRESHOLD` | `90` | คะแนนขั้นต่ำ ลดเป็น `80` ถ้าอยากได้สัญญาณถี่ขึ้น |
| `MAX_SIGNALS_PER_DAY` | `0` | **0 = ไม่จำกัด** ใส่ตัวเลขถ้าอยากจำกัด |
| `MAX_SIGNALS_PER_RUN` | `0` | **0 = ไม่จำกัด** ส่งได้หลาย symbol ในรอบเดียว |
| `COOLDOWN_MINUTES` | `0` | **0 = ไม่มี cooldown** |
| `USE_KILL_ZONES` | `false` | **วิเคราะห์ทุกชั่วโมงที่ตลาดเปิด** ตั้ง `true` ถ้าอยากเฉพาะ Kill Zone |
| `BRIEFING_MINUTES` | `60` | รายงานวิเคราะห์กราฟทุกกี่นาที (0 = ปิด) |
| `SEND_STATUS_REPORT` | `false` | ตั้ง `true` ถ้าอยากได้รายงานสั้นทุกรอบ (ข้อความเยอะมากที่ความถี่ 5 นาที) |
| `ENTRY_TIMEFRAME` | `M15` | หรือ `H1` ถ้าอยากได้สัญญาณระยะยาวขึ้น |

> 🛡️ **กันสแปมอัตโนมัติ** แม้ปิดโควตาทั้งหมดแล้ว ระบบยังกัน 2 ชั้น:
> ไม่ส่งซ้อน symbol เดิมขณะมีสัญญาณ active · ไม่ส่งซ้ำแท่งเทียนเดิม (แม้สแกน 3 รอบใน 1 แท่ง M15)

**ผ่อนเงื่อนไข SMC** (ถ้าไม่มีสัญญาณเลยหลายวัน) — ปรับทีละตัว อย่าปิดพร้อมกัน:
`REQUIRE_MITIGATION` → `REQUIRE_FVG` → `REQUIRE_SWEEP` → `REQUIRE_ORDER_BLOCK` (ตั้งเป็น `false`)

## เปิดออเดอร์บนมือถือเมื่อได้สัญญาณ

**1. คำนวณ lot ตามความเสี่ยงของคุณ** (ระบบไม่คำนวณให้ เพราะไม่รู้ขนาดพอร์ต)
```
Lot = (เงินทุน × %ความเสี่ยง) ÷ (ระยะ SL เป็นจุด × มูลค่าต่อจุด)
```
ตัวอย่าง: ทุน $1,000 · เสี่ยง 1% = $10 · SL ห่าง 670 จุด (ทอง 0.01 lot ≈ $0.10/จุด)
→ lot ≈ **0.15**

**2. เปิดแอปโบรกเกอร์ (MT5/MT4 มือถือ)** → เลือก symbol → **New Order**
- Volume = lot ที่คำนวณได้
- **Stop Loss = ใส่ทุกครั้ง** ← ห้ามข้ามเด็ดขาด
- Take Profit = TP1 (หรือ TP2 ถ้าอยากถือยาว)

**3. เมื่อได้ ✅ TP1 Hit** → ปิดครึ่งหนึ่ง + เลื่อน SL มาที่ราคาเข้า (Break Even)

**4. เมื่อได้ ❌ Signal Cancelled** → ยังไม่เข้า = ไม่ต้องเข้า / เข้าแล้ว = พิจารณาปิดก่อนโดน SL

## ข้อจำกัดที่ต้องรู้จริง ๆ

1. **โควตา GitHub Actions ← เรื่องสำคัญที่สุด**

   | ความถี่ | รอบ/เดือน | นาที/เดือน | repo ส่วนตัว (ฟรี 2,000 น.) |
   |---|---|---|---|
   | ทุก 5 นาที (ปัจจุบัน) | ~6,300 | ~6,300 | ❌ **เกิน 3 เท่า** หมดราววันที่ 10 |
   | ทุก 15 นาที | ~2,100 | ~2,100 | ⚠️ เกินนิดหน่อย |
   | ทุก 30 นาที | ~1,050 | ~1,050 | ✅ พอดี |

   GitHub คิดเงินเป็น**นาที ปัดขึ้น** ต่อ 1 รอบ แม้รอบจะใช้จริงแค่ 25 วินาที

   **ทางแก้ 2 ทาง:**
   - **เปลี่ยน repo เป็น Public** → รันฟรีไม่จำกัด (Settings → เลื่อนล่างสุด → Change visibility)
     token ยังปลอดภัยเพราะเก็บใน Secrets ไม่ได้อยู่ในโค้ด แต่คนอื่นจะเห็นตรรกะการเทรดของคุณ
   - **หรือคงเป็น Private แล้วลดความถี่** เป็นทุก 30 นาที (แก้บรรทัด `cron` ใน `.github/workflows/signal-bot.yml`)

2. **เวลารันไม่เป๊ะ** — GitHub cron อาจช้ากว่าเวลาที่ตั้ง 5–15 นาทีในช่วงที่คนใช้เยอะ ไม่เหมาะกับ scalping ที่ต้องการความเร็ววินาที

3. **สแกนทุก 5 นาที** — ถี่พอสำหรับ entry M15 (สแกน 3 รอบต่อ 1 แท่ง) แต่ราคาจริงตอนเข้ายังต่างจากในสัญญาณเล็กน้อย **ให้ดูโซน Entry Zone เป็นหลัก อย่าไล่ราคา**

4. **GitHub ปิด schedule อัตโนมัติ** ถ้า repo ไม่มีความเคลื่อนไหว 60 วัน — แต่บอทตัวนี้ commit สถานะกลับทุกครั้งที่มีสัญญาณ จึงนับเป็นความเคลื่อนไหว ปกติจะไม่โดนปิด (ถ้าเงียบนานมากให้เข้าไปกด Run workflow สักครั้ง)

5. **ราคาไม่ตรงโบรกเกอร์เป๊ะ** — ต่างกันเล็กน้อยเสมอ ใช้เป็นแนวทาง ไม่ใช่ตัวเลขตายตัว

6. **ไม่รับประกันผลกำไร** — สัญญาณคือความน่าจะเป็น ควรทดลองดูเฉย ๆ 2–4 สัปดาห์ก่อนใช้เงินจริง

## อยากได้ความแม่นยำระดับ MT5 จริง ๆ?

ระบบนี้กับ EA ใน `MQL5/` ใช้ตรรกะ SMC ชุดเดียวกัน ต่างกันที่:

| | GitHub Actions (ตัวนี้) | MT5 EA |
|---|---|---|
| ต้องมีคอม/VPS | ❌ ไม่ต้อง | ✅ ต้องมี |
| ตั้งค่าจากมือถือ | ✅ ได้ | ❌ ไม่ได้ |
| ความถี่วิเคราะห์ | ทุก 30 นาที | ทุก tick |
| ราคา | Yahoo/TwelveData | ราคาโบรกเกอร์จริง |
| ค่าใช้จ่าย | ฟรี | ค่า VPS ~$5–15/เดือน |

เริ่มจากตัวนี้ก่อนได้เลย ถ้าติดใจแล้วอยากได้ความแม่นยำสูงขึ้นค่อยย้ายไป MT5 EA ทีหลัง
