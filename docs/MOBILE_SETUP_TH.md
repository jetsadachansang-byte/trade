# ตั้งค่าสัญญาณเข้า Telegram จากมือถือ (ไม่ต้องใช้คอม ไม่ต้องเปิด MT5)

ระบบนี้ให้ **GitHub รันการวิเคราะห์ให้ฟรี** ตามเวลาที่ตั้งไว้ แล้วส่งสัญญาณเข้า Telegram
ทุกขั้นตอนทำบนมือถือได้ ใช้เวลาประมาณ 15 นาที ตั้งครั้งเดียวจบ

```
[ GitHub รันให้ฟรีทุก 30 นาที ]         [ มือถือคุณ ]
   ดึงราคา → วิเคราะห์ SMC     ──────►   Telegram เด้งสัญญาณ
   ติดตาม TP/SL ให้ต่อเนื่อง               เปิดออเดอร์ในแอปโบรกเกอร์
```

**ไม่ต้องเปิดคอม ไม่ต้องมี VPS ไม่ต้องติดตั้ง MT5**

---

## ขั้นที่ 1 — สร้างบอท Telegram (3 นาที)

1. เปิดแอป **Telegram** → ค้นหา **@BotFather** (ตัวที่มีติ๊กน้ำเงิน)
2. กด **Start** → พิมพ์ `/newbot`
3. ตั้งชื่อบอท เช่น `CapitalGuard Signal`
4. ตั้ง username ต้องลงท้ายด้วย `bot` เช่น `mysignal_2026_bot`
5. BotFather ส่ง **token** กลับมา หน้าตาแบบนี้:
   ```
   8123456789:AAHk3_xYzAbCdEfGhIjKlMnOpQrStUvWxYz
   ```
   **แตะค้างเพื่อคัดลอกเก็บไว้**

> 🔒 ห้ามให้ token นี้กับใคร ถ้าหลุดพิมพ์ `/revoke` กับ BotFather เพื่อออกใหม่

---

## ขั้นที่ 2 — หา Chat ID (1 นาที)

1. ค้นหาบอทที่เพิ่งสร้าง (พิมพ์ username ที่ตั้งไว้) → กด **Start**
   ⚠️ ต้องกด Start ก่อน ไม่งั้นบอทส่งข้อความหาคุณไม่ได้
2. ค้นหาบอทชื่อ **@userinfobot** → กด **Start**
3. บอทจะตอบกลับมาพร้อม **Id** เช่น `123456789` → **คัดลอกเก็บไว้**

---

## ขั้นที่ 3 — ใส่ค่าลับใน GitHub (5 นาที)

เปิดเบราว์เซอร์บนมือถือ (Chrome/Safari) ไปที่ repo ของคุณ:
`github.com/jetsadachansang-byte/trade`

> 💡 แนะนำกดปุ่ม **"Desktop site"** ในเมนูเบราว์เซอร์ เมนูจะครบกว่าและกดง่ายกว่า

1. แตะ **Settings** (แท็บด้านบน)
2. เมนูซ้าย → **Secrets and variables** → **Actions**
3. กดปุ่ม **New repository secret** แล้วเพิ่ม 2 ตัวนี้ทีละตัว:

| Name | Secret |
|---|---|
| `TELEGRAM_BOT_TOKEN` | token จากขั้นที่ 1 |
| `TELEGRAM_CHAT_ID` | เลข Id จากขั้นที่ 2 |

พิมพ์ชื่อให้ตรงเป๊ะ (ตัวใหญ่ทั้งหมด มีขีดล่าง) แล้วกด **Add secret**

---

## ขั้นที่ 4 — เปิด GitHub Actions (1 นาที)

1. กลับไปหน้า repo → แตะแท็บ **Actions**
2. ถ้าเห็นข้อความให้เปิดใช้งาน → กด **"I understand my workflows, go ahead and enable them"**
3. เมนูซ้ายจะเห็น workflow ชื่อ **CapitalGuard Signal Bot**

---

## ขั้นที่ 5 — ทดสอบทันที (2 นาที)

1. แตะ **CapitalGuard Signal Bot** ในเมนูซ้าย
2. กดปุ่ม **Run workflow** (ปุ่มสีเทาด้านขวา)
3. ติ๊ก ✅ **ส่งรายงานสถานะเข้า Telegram ด้วย**
4. ติ๊ก ✅ **ข้ามการเช็คเวลาตลาด/kill zone** (เพื่อให้ทดสอบได้ทุกเวลา)
5. กด **Run workflow** สีเขียว
6. รอ 1–2 นาที → เปิด Telegram

**ต้องได้ข้อความรายงานสถานะเข้ามา** แบบนี้:
```
🔍 รายงานสถานะ
สัญญาณวันนี้: 0 | กำลังติดตาม: 0

รอที่ขั้นตอน:
• XAUUSD: 7-sweep — ยังไม่เกิด liquidity sweep
• EURUSD: 1-structure — โครงสร้าง D1/H4/H1 ไม่ตรงกัน
• GBPUSD: 5-orderblock — ไม่พบ order block
```

ได้ข้อความนี้ = **ระบบทำงานครบวงจรแล้ว** จากนี้จะรันเองทุก 30 นาที

ถ้าไม่ได้ → ดูหัวข้อ [แก้ปัญหา](#แก้ปัญหา) ด้านล่าง

---

## ขั้นที่ 6 — ปล่อยให้ทำงานเอง

เสร็จแล้วครับ ไม่ต้องทำอะไรอีก ระบบจะ:
- วิเคราะห์ทุก 30 นาที ในวันจันทร์–ศุกร์
- ส่งสัญญาณเฉพาะตอนเจอ setup คะแนน ≥ 90
- ติดตาม TP1/TP2/TP3/SL ให้อัตโนมัติ แล้วแจ้งเข้า Telegram

**ปิดแอปได้ ปิดมือถือได้ ระบบยังทำงานต่อบน GitHub**

## ปรับแต่งค่าต่าง ๆ (ทำทีหลังได้)

**Settings → Secrets and variables → Actions → แท็บ Variables → New repository variable**

| ชื่อ Variable | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `TIER1_SYMBOLS` | `XAUUSD` | สินทรัพย์หลัก |
| `TIER2_SYMBOLS` | `EURUSD,GBPUSD,USDJPY` | คู่เงินหลัก |
| `TIER3_SYMBOLS` | (ว่าง) | คู่เงินรอง เช่น `EURJPY,GBPJPY` |
| `SCORE_THRESHOLD` | `90` | คะแนนขั้นต่ำ ลดเป็น `80` ถ้าอยากได้สัญญาณถี่ขึ้น |
| `MAX_SIGNALS_PER_DAY` | `3` | จำกัดต่อวัน |
| `USE_KILL_ZONES` | `true` | ตั้ง `false` ถ้าอยากวิเคราะห์ทั้งวัน |
| `SEND_STATUS_REPORT` | `false` | ตั้ง `true` ถ้าอยากได้รายงานทุกรอบ (ข้อความเยอะ) |
| `ENTRY_TIMEFRAME` | `M15` | หรือ `H1` ถ้าอยากได้สัญญาณระยะยาวขึ้น |

**ผ่อนเงื่อนไข SMC** (ถ้าไม่มีสัญญาณเลยหลายวัน) — ปรับทีละตัว อย่าปิดพร้อมกัน:
`REQUIRE_MITIGATION` → `REQUIRE_FVG` → `REQUIRE_SWEEP` → `REQUIRE_ORDER_BLOCK` (ตั้งเป็น `false`)

## ข้อมูลราคาแม่นแค่ไหน

ค่าเริ่มต้นใช้ **Yahoo Finance ฟรี ไม่ต้องสมัคร** — ทองใช้ราคา futures (GC=F) ซึ่งวิ่งตามราคา spot ใกล้เคียงมาก แต่ **ตัวเลขจะต่างจากโบรกเกอร์ของคุณเล็กน้อย**

ถ้าอยากได้ข้อมูลแม่นและเสถียรกว่า (แนะนำ):
1. สมัครฟรีที่ [twelvedata.com](https://twelvedata.com) (ใช้มือถือได้ ใช้อีเมลอย่างเดียว)
2. คัดลอก API key
3. เพิ่มเป็น Secret ชื่อ `TWELVEDATA_API_KEY`
4. เพิ่ม Variable `REQUEST_PAUSE` = `8` (แผนฟรีจำกัด 8 request/นาที)

ระบบจะใช้ Twelve Data ก่อน ถ้าล้มจะสลับไป Yahoo ให้อัตโนมัติ

> ⚠️ **ราคาที่ใช้วิเคราะห์ต่างจากโบรกเกอร์เล็กน้อยเสมอ** — ใช้ระดับ SL/TP ในสัญญาณเป็นแนวทาง
> แล้วปรับตามราคาจริงในแอปโบรกเกอร์ของคุณ

## เปิดออเดอร์บนมือถือเมื่อได้สัญญาณ

**1. คำนวณ lot ตามความเสี่ยงของคุณ** (ระบบไม่คำนวณให้ เพราะไม่รู้ขนาดพอร์ต)
```
Lot = (เงินทุน × %ความเสี่ยง) ÷ (ระยะ SL เป็นจุด × มูลค่าต่อจุด)
```
ตัวอย่าง: ทุน $1,000 · เสี่ยง 1% = $10 · SL ห่าง 670 จุด (ทอง 0.01 lot ≈ $0.10/จุด)
→ lot ≈ **0.15**

**2. เปิดแอปโบรกเกอร์ (MT5/MT4 มือถือ)** → เลือก symbol → **New Order**
- Volume = lot ที่คำนวณได้
- **Stop Loss = ใส่ทุกครั้ง** ← ห้ามข้ามเด็ดขาด
- Take Profit = TP1 (หรือ TP2 ถ้าอยากถือยาว)

**3. เมื่อได้ ✅ TP1 Hit** → ปิดครึ่งหนึ่ง + เลื่อน SL มาที่ราคาเข้า (Break Even)

**4. เมื่อได้ ❌ Signal Cancelled** → ยังไม่เข้า = ไม่ต้องเข้า / เข้าแล้ว = พิจารณาปิดก่อนโดน SL

## แก้ปัญหา

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| ไม่ได้ข้อความเลย | ยังไม่ได้กด Start คุยกับบอท | เปิด Telegram ทักบอทก่อน แล้วรัน workflow ใหม่ |
| Actions ขึ้นสีแดง | Secret ผิดชื่อหรือไม่มี | Settings → Secrets → เช็คชื่อให้ตรงเป๊ะ |
| log ขึ้น `config: TELEGRAM_BOT_TOKEN ยังไม่ได้ตั้ง` | ยังไม่ได้ใส่ Secret | ทำขั้นที่ 3 ใหม่ |
| log ขึ้น `Telegram error 400` | chat id ผิด | หา Id ใหม่ด้วย @userinfobot |
| log ขึ้น `Telegram error 401` | token ผิด | ขอ token ใหม่จาก @BotFather (`/mybots`) |
| ไม่มีสัญญาณเลยหลายวัน | **ปกติตามดีไซน์** | เปิด `SEND_STATUS_REPORT=true` ดูว่ารอที่ขั้นไหน |
| `yahoo: HTTP 429` | Yahoo จำกัดการเรียก | สมัคร Twelve Data (ดูหัวข้อด้านบน) |

**ดู log เต็ม:** แท็บ **Actions** → แตะรอบที่รัน → แตะ **scan** → กางขั้นตอน "วิเคราะห์ตลาดและส่งสัญญาณ"

## ข้อจำกัดที่ต้องรู้จริง ๆ

1. **โควตา GitHub Actions** — repo สาธารณะรันฟรีไม่จำกัด, repo ส่วนตัวได้ 2,000 นาที/เดือน
   ทุก 30 นาที × วันทำการ ≈ 1,000–1,500 นาที/เดือน (พอดีโควตา) ถ้าจะรันถี่กว่านี้ควรเปลี่ยน repo เป็น public

2. **เวลารันไม่เป๊ะ** — GitHub cron อาจช้ากว่าเวลาที่ตั้ง 5–15 นาทีในช่วงที่คนใช้เยอะ ไม่เหมาะกับ scalping ที่ต้องการความเร็ววินาที

3. **สแกนทุก 30 นาที** — ถ้าใช้ entry M15 ระบบอาจเห็น setup ช้าไป 1–2 แท่ง ราคาจริงตอนเข้าจะต่างจากในสัญญาณ **ให้ดูโซน Entry Zone เป็นหลัก อย่าไล่ราคา**

4. **GitHub ปิด schedule อัตโนมัติ** ถ้า repo ไม่มีความเคลื่อนไหว 60 วัน — แต่บอทตัวนี้ commit สถานะกลับทุกครั้งที่มีสัญญาณ จึงนับเป็นความเคลื่อนไหว ปกติจะไม่โดนปิด (ถ้าเงียบนานมากให้เข้าไปกด Run workflow สักครั้ง)

5. **ราคาไม่ตรงโบรกเกอร์เป๊ะ** — ต่างกันเล็กน้อยเสมอ ใช้เป็นแนวทาง ไม่ใช่ตัวเลขตายตัว

6. **ไม่รับประกันผลกำไร** — สัญญาณคือความน่าจะเป็น ควรทดลองดูเฉย ๆ 2–4 สัปดาห์ก่อนใช้เงินจริง

## อยากได้ความแม่นยำระดับ MT5 จริง ๆ?

ระบบนี้กับ EA ใน `MQL5/` ใช้ตรรกะ SMC ชุดเดียวกัน ต่างกันที่:

| | GitHub Actions (ตัวนี้) | MT5 EA |
|---|---|---|
| ต้องมีคอม/VPS | ❌ ไม่ต้อง | ✅ ต้องมี |
| ตั้งค่าจากมือถือ | ✅ ได้ | ❌ ไม่ได้ |
| ความถี่วิเคราะห์ | ทุก 30 นาที | ทุก tick |
| ราคา | Yahoo/TwelveData | ราคาโบรกเกอร์จริง |
| ค่าใช้จ่าย | ฟรี | ค่า VPS ~$5–15/เดือน |

เริ่มจากตัวนี้ก่อนได้เลย ถ้าติดใจแล้วอยากได้ความแม่นยำสูงขึ้นค่อยย้ายไป MT5 EA ทีหลัง
